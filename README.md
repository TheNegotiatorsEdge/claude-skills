# The Negotiator's Edge — MAGNETIC Influence

A Claude skill that coaches you through real negotiation and influence situations using the
**MAGNETIC Influence** framework from Tim Castle's book *Magnetic Influence*.

Bring it a negotiation, a draft email, a deal decision, a pitch, or a tricky conversation, and
Claude will assess it across eight trust-based principles, identify what's weak, and hand back
specific, usable guidance — including a line to say and a line to avoid.

## What it does

When the skill is active, Claude:

1. Reads your situation (a draft message, a transcript, or a described scenario).
2. Scores it across the eight MAGNETIC principles — **M**eaningful Impact, **A**uthenticity,
   **G**ravitas/Generosity/Gratitude, **N**etworking, **E**nergetic Vibration, **T**rust,
   **I**ntuition, **C**onnection.
3. Picks a posture — Advance, Stabilize, or Repair.
4. Returns a tight coaching response: your score, strengths, risk areas, best next move, one
   line to say, and one line to avoid.

It is built around **principled, trust-based influence** — never manipulation, pressure, or
hard closes.

## Safety / contents

This skill contains **only instructions and reference text** (Markdown). It bundles no scripts,
no executable code, and no external dependencies. It does not access the network or the file
system.
